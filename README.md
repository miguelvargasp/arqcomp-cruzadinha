# Cruzada Entrecruzada

Jogo de cruzadinha sobre Arquitetura Computacional, desenvolvido em HTML, CSS e JavaScript puros.



## Como jogar
1. Abra este link: [text](https://miguelvargasp.github.io/arqcomp-cruzadinha/) em um navegador.
2. Leia as pistas Horizontais e Verticais.
3. Clique nas casas e digite uma letra por casa.
4. Clique em **Conferir respostas** para verificar as palavras e acompanhar a pontuação.
5. Clique em **Reiniciar** para limpar o tabuleiro.

## Palavras e pistas

| Palavra | Pista |
|---|---|
| CPU | Parte do computador que busca e executa as instruções dos programas. |
| ULA | Bloco responsável por realizar cálculos e operações lógicas. |
| UC | Interpreta as instruções e envia comandos às demais partes do processador. |
| REGISTRADORES | Pequenas memórias internas que guardam dados usados naquele momento. |
| RAM | Memória de trabalho que guarda programas em execução e os dados utilizados. |
| ROM | Memória não volátil que tradicionalmente armazena instruções essenciais à inicialização. |
| EEPROM | Memória regravável que conserva configurações mesmo quando o equipamento fica sem energia. |
| FLASH | Memória não volátil e regravável que guarda o programa do Arduino. |
| CACHE | Memória pequena e rápida que mantém cópias de dados usados recentemente. |
| DMA | Recurso que permite transferir dados à memória sem ocupar o processador a cada byte. |
| ADDRESSBUS | Conjunto de fios que indica a posição de memória ou dispositivo que será acessado. |
| DATABUS | Via que transporta valores lidos ou escritos e também instruções entre componentes. |

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: aparência e responsividade.
- `script.js`: tabuleiro, pistas, navegação e verificação.
